# the-way-of-grace

The curriculum at [quant-lessons](https://github.com/5x5x5x5/quant-lessons), redirected by a different voice. Same math. Same code references. Same trading project at the end of every lesson. Everything else — the pace, the whispered asides, the image of light across a strike — rethought in Terence Malick's register.

**Site:** https://5x5x5x5.github.io/the-way-of-grace/

## Local development

```bash
uv sync
uv run mkdocs serve  # live reload at localhost:8000
```

## Deploy

Pushes to `main` trigger `.github/workflows/deploy.yml`, which runs `mkdocs gh-deploy --force` and publishes to the `gh-pages` branch.

## Figures

Figures in `docs/assets/figures/` are generated by `scripts/generate_figures.py` (deterministic; fixed seeds). They are the same figures served on the quant-lessons site — the mathematics does not change with the voice.

```bash
uv run python scripts/generate_figures.py
```
